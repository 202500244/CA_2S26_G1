# Documento de Planificación – Capacitación sobre APIs REST

## 1. Tema elegido

El tema seleccionado para la capacitación es **APIs REST**.

Este tema fue elegido porque permite explicar de manera clara y práctica cómo se comunican las aplicaciones mediante peticiones y respuestas, incluyendo la relación entre frontend, backend y base de datos.

Durante la planificación se consideraron también los temas **Ética del hacking** y **Cifrado de información**, pero finalmente se seleccionó APIs REST por permitir combinar explicación teórica con ejemplos y una actividad práctica.

---

## 2. Lista preliminar de subtemas

| No. | Subtema | Contenido |
|---|---|---|
| 1 | Introducción a las API REST | Definición de API, significado de REST, propósito y ejemplos cotidianos. |
| 2 | Arquitectura y funcionamiento | Cliente, servidor, API, frontend, backend, base de datos, endpoints, peticiones y respuestas. |
| 3 | Métodos HTTP | GET, POST, PUT, PATCH y DELETE. |
| 4 | Intercambio de información | URL, parámetros, headers, body, JSON y códigos HTTP. |
| 5 | Seguridad en API REST | HTTPS, autenticación, autorización, tokens, roles y validación. |
| 6 | Ejercicio práctico | Aplicación de los conceptos vistos mediante un proyecto de Gestor de Tareas |

## 4. Perfil de la audiencia y estrategia de adaptación del mensaje

### Perfil de la audiencia

La capacitación está dirigida a:

- Estudiantes de diversificado con orientación en computación.
- Estudiantes universitarios de primeros semestres.

Se espera que los participantes tengan:

- Uso básico de computadora e Internet.
- Conceptos elementales de programación.
- No se requiere experiencia previa con APIs.

### Estrategia de adaptación del mensaje

Para adaptar el contenido al nivel de la audiencia se utilizarán las siguientes estrategias:

- Explicar primero los conceptos mediante ejemplos cotidianos.
- Utilizar diagramas simples para representar la comunicación entre cliente, API, servidor y base de datos.
- Evitar profundizar en conceptos demasiado avanzados.
- Utilizar ejemplos sencillos de métodos HTTP y respuestas JSON.
- Realizar una actividad práctica para reforzar los conceptos explicados.
- Finalizar con un cuestionario corto para comprobar la comprensión del contenido.
